# TP: Funciones

## Descripcion
Este proyecto corresponde al Tp de cv. Contiene soluciones para el tp de cv, implementando en cada caso **funciones nombradas** y **funciones anónimas (lambda)**.

## Tecnologías utilizadas
- **Python 3.x**: Lenguaje de programación utilizado.
- **Git & GitHub**: Control de versiones y alojamiento del repositorio.

## Funciones e Implementaciones (Consignas)
1. **Suma de dos numeros**: Recibe dos números en el orden proporcionado y devuelve el resultado de la suma.
2. **Resta con parametros nombrados**: Permite restar dos números especificando explícitamente el orden de los argumentos (`num1` y `num2`).
3. **Calculo de precio final (IVA)**: Aplica un IVA por defecto del 21% sobre el precio de un producto, permitiendo modificar el porcentaje si se especifica.
4. **Conversor de unidades**: Convierte metros a centimetros por defecto, o a milímetros si se aclara mediante parámetros.
5. **Calculo de area**: Calcula el área a partir de la base y la altura; si no se especifica la altura, asume que es igual a la base (cuadrado).
